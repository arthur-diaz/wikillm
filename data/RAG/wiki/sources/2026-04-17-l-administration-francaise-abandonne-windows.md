# L'administration française abandonne Windows

L'administration française abandonne Windows pour se tourner vers Linux et renforcer sa souveraineté numérique.

## Points clés

- L'administration française abandonne Windows pour Linux
- La souveraineté numérique est un objectif clé
- La dépendance vis-à-vis des technologies américaines est réduite
